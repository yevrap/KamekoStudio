# Iteration NN — <goal in one line>

Copy this folder's four files into `docs/studio/iterations/NN/` at the start of an
iteration: `plan.md`, `log.md`, `review.md`, `retro.md`. Tickets go in `tickets/`.

## plan.md

- **Goal:** one sentence. If it needs two, it is two iterations.
- **Committed tickets:** table of ID, title, size, role lead.
- **Reserved capacity:** which tickets are the debt / docs / learning share.
- **Risks:** what could stop this, and the response to each.
- **Out of scope:** what was explicitly not taken.

## log.md

Three lines per role that acted, per stand-up: done / next / blocked.

## review.md

- **Demo:** what to look at, with URLs.
- **Per item:** what it does, what changed, and a Keep / Iterate / Kill line for the
  executive to answer.
- **Checks:** every check, with pass / fail / not run.
- **Not done:** committed tickets that did not land, and why.

## retro.md

- **Went well**
- **Didn't**
- **Change next time** — each change becomes a ticket or an edit to a process document,
  named here with its ID.
- **Reserved capacity:** was the 20% used, and on what.
