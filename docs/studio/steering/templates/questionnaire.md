# Shadow Studio — Questionnaire Template

*Copy to `Shadow Studio — <topic> Questionnaire.md` when the company needs a decision that
is genuinely yours. Questions go here, not into chat.*

## Rules for whoever writes one

- Only decisions that change what gets built. Anything the team can reason out, it reasons
  out and records instead.
- Every question gets a **⭐ default**, so silence is an answer and nothing blocks on you.
- Give the trade-off in one line, not a briefing.
- Four questions is a lot. Ten is a sign the team hasn't done its thinking.
- Answered questions are folded into the design note and **removed from here**, so the
  questionnaire always shows only what is still open.
