## Say this

| You say | What happens |
|---|---|
| **"studio next"** | The team does the next step of its sprint (plan, build one ticket, review, close or retro), then stops and tells you. Start a new session for each. Skill: `studio-iteration` |
| **"studio next — focus: X"** | The same, and the next sprint is planned around X |
| **"studio status"** | Read-only: where it is, what's open, the trend. Skill: `studio-standup` |
| **"promote X"** | Prepares a move into the production arcade, for your approval. Skill: `studio-promote` |
| **anything, in chat** | Logged in [Shadow Studio — Input Ledger](input-ledger.md), triaged, and reported back |
| **"stop"** | Halts at the next step. A `STOP` file at the repo root does the same |

## The realm itself

`studio/` in the repo → https://yevrap.github.io/KamekoStudio/studio/

Iteration 01 gave the realm its Backstage identity and a shelf built from one data file.
Iteration 02 put the first thing on it: **Overtighten**, a plate of bolts, built to test
whether the coupling between them would make each plate an ordering puzzle. It does not —
and the game's own page says so, which is the point of an experimental realm. Every page
under `studio/` now boots under assertion in a phone-emulated Chrome.

Iteration 03 was maintenance: the realm looks the same apart from its pulse and retro lines.
*Overtighten* stays on the shelf as an honest prototype (Q7).

Iteration 04 made the studio's first fix to a production game. Black Hole in One no longer
throws when you enter Explore with a golf hole's spirals still alive (TD-009). It was done
under your Q9 permission, written into the repo as ADR-0008. Review taught it one rule the
plan hadn't: a production fix waits for an independent review before it goes live, and
goes out exactly as reviewed.

Iteration 05 opened epic E1, the Studio Wing: the 3D landing page becomes the studio's
window. River Run is the first fork, a copy in `studio/games/river-run/` with saves of its
own, and the 3D page's River Run portal now leads to it. Sprint 06 runs its first
experiment.

**Open decisions:** Q12 (which River Run experiment goes first; ⭐ power-ups if blank at
plan 06), Q10 (should a production fix also need your approval?), Q1 (the name) and Q5
(anything else), in [Shadow Studio — Questionnaire](questionnaire.md). Keep / Iterate / Kill on
iteration 05 is in `docs/studio/iterations/05/review.md`.
