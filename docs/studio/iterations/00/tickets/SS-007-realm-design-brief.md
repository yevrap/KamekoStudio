# SS-007 — The realm design brief

- **Status:** Done
- **Size:** M
- **Iteration:** 00
- **Role lead:** UX / Art Direction
- **Depends on:** SS-005
- **Branch:** none — the brief lives outside the repository

## Motivation

The realm needs an identity, and the identity is a decision the executive should make from
real options rather than inherit from whatever the placeholder happened to look like.

## Acceptance criteria

- [x] States what the realm has to communicate before proposing how it should look.
- [x] Three distinct directions, each with a palette, a mood, a motion and a status treatment, and an honest argument against it.
- [x] One recommendation, with the reasoning.
- [x] How the portal transition should feel, including what it deliberately does not do.
- [x] The gallery and home layout, sketched, including how killed work appears.
- [x] The portal's real cost, from the SS-005 survey, and the two separate approvals it needs.
- [x] Every decision it asks for appears in a questionnaire note, not in chat.

## Evidence plan

A read: could someone pick a direction from this without asking a follow-up question.

## Out of scope

Building any of it.

---

## Result

- **What changed:** `Shadow Studio — Realm Design Brief` in the vault, and four open
  questions in `Shadow Studio — Questionnaire` (name, identity, the portal-capacity fix,
  the studio's own portal), each with a ⭐ default so silence is an answer.
- **Tested by:** each direction stated with palette, motion, status treatment and a
  counter-argument; the two portal approvals separated, because one is a production bug fix
  worth doing regardless and the other is not.
- **Deferred:** all of the building, by design.
- **Fix rounds used:** 0 / 2
