Overtighten

PROTOTYPE Seat every bolt inside its band — all of them at once. Turning any bolt loosens the ones it is coupled to, and past the strip point a thread is gone.

All three plates seated. That is every plate this experiment has — there is no progression layer behind it yet, on purpose.

What this is

The first experiment built by the studio's own team. It exists to find out whether one idea holds up: that the interesting part of tightening a plate is the coupling between bolts, not the timing of a release. Torque only goes onto a bolt directly, and only comes off it by turning one of its neighbours — so an overshoot is recoverable, but never for free.

Each plate's bolts, bands and couplings are one entry in a data file, and a solver proves every shipped plate can be cleared from zero without stripping a thread. A second test proves the opposite of the lazy case: none of them can be cleared by holding each bolt once. If that test ever passes, the coupling has become decoration.
