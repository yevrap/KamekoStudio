How the team works

  • One run is one iteration: plan, build, test, review, retro, stop.
  • It may only write inside studio/, docs/studio/ and tests/studio/. Everything else is out of bounds.
  • npm run studio:check enforces that, plus the storage namespace, public-repo hygiene, and the honesty of the documents.
  • Every check reports pass, fail or not run. Nothing is skipped quietly.

The handbook is in the repository under docs/studio/, starting with its README.
